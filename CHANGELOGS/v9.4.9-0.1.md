# v9.4.9-0.1.0 Changelog

基于 Grafana v9.4.9 的定制版本。

## 新功能

### 快照对象存储支持

- **新增对象存储后端**: 快照数据现在可以存储到对象存储中，避免数据库膨胀
  - 支持腾讯云 COS 存储
  - 支持 S3 兼容存储（如 MinIO、阿里云 OSS）
  - 配置项位于 `[snapshots.object_storage]` 节点

配置示例：
```ini
[snapshots.object_storage]
# 对象存储提供商 (tencent, s3, oss, minio)
provider = tencent

# 端点 URL（包含 bucket 和 region）
# 腾讯云 COS: https://<bucket>.cos.<region>.myqcloud.com
endpoint = https://your-bucket.cos.ap-guangzhou.myqcloud.com

# 访问密钥
secret_id = your-secret-id
secret_key = your-secret-key

# 快照对象路径前缀
path_prefix = never-delete-me/
```

## 改进

### 快照功能优化

- **调整默认超时时间**: 快照创建默认超时从 4 秒调整为 30 秒，适应大型仪表板数据收集
- **按钮描述优化**: 本地快照按钮文字从 "Local Snapshot" 改为 "Create Snapshot"

## 配置变更

| 配置项 | 位置 | 说明 |
|--------|------|------|
| `provider` | `[snapshots.object_storage]` | 对象存储类型 |
| `endpoint` | `[snapshots.object_storage]` | 对象存储端点 URL |
| `secret_id` | `[snapshots.object_storage]` | 访问密钥 ID |
| `secret_key` | `[snapshots.object_storage]` | 访问密钥 |
| `path_prefix` | `[snapshots.object_storage]` | 对象路径前缀 |
